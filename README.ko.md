# manga-filter

컬러 일러스트를 스크린톤이 들어간 흑백 만화로 바꿉니다. 일반적인 이미지 처리만 쓰고 머신러닝 모델은 쓰지 않습니다.

**온라인에서 사용하기: <https://jannchie.github.io/manga-filter/>**

도구 전체가 [`index.html`](index.html) 파일 하나입니다. 브라우저로 열고 이미지를 끌어다 놓거나 붙여 넣은 뒤 슬라이더를 움직이면 결과가 바로 바뀝니다. 모든 처리는 브라우저의 Web Worker 안에서 이루어지므로 설치할 것이 없고, 이미지가 내 컴퓨터 밖으로 나가지도 않습니다.

## 사용법

1. <https://jannchie.github.io/manga-filter/>을 열거나, 최신 브라우저로 `index.html`을 엽니다.
2. "이미지 열기"를 누르거나 이미지를 캔버스로 끌어다 놓습니다. 클립보드에서 붙여 넣어도 됩니다. 버튼 옆의 썸네일 두 개는 예시 이미지입니다.
3. 프리셋을 고른 뒤 슬라이더를 조정합니다. "자동"은 이미지에 맞춰 블랙·화이트 포인트, 채도 높은 색 밝히기, 선수를 정하고, 다른 프리셋은 이를 바탕으로 합니다. "누르고 있으면 원본 보기"를 누르는 동안 원본과 비교할 수 있습니다.
4. "파라미터 복사"는 현재 설정을 JSON으로 복사하고, "기본값으로"는 현재 이미지의 자동 설정으로 되돌립니다.

미리보기에서는 휠로 포인터 위치를 중심으로 확대·축소하고, 드래그로 이동하며, 더블클릭으로 창에 맞춤과 1:1을 오갑니다. `0`은 창에 맞춤, `1`은 1:1입니다. 슬라이더는 클릭해서 선택한 뒤 휠로 미세 조정할 수 있고(Shift를 누르면 10단계씩), 더블클릭하면 초기값으로 돌아갑니다.

## 하는 일

처리 과정은 [ashukae/ComfyUI-MangaScreen](https://github.com/ashukae/ComfyUI-MangaScreen)의 Manga Levels와 Manga Finish 노드를 옮긴 것입니다(MIT, 라이선스는 [`licenses/`](licenses/)). 흑백 레벨 보정, 선과 먹칠의 잉크 레이어, 망점 제거와 평탄화, 작은 영역을 합친 톤 배치, 그러데이션 톤, 페이지 전체에 맞춘 망, 먹칠 안에 흰 선을 파내는 처리를 합니다. 여기에 다음을 더했습니다.

- **가는 선**: 원본의 L\* 채널에 두 가지 크기의 DoG(가우시안 차)를 적용해 입, 코, 옅은 윤곽선을 되살립니다. 원래 구현은 이런 선을 얻으려면 외부 신경망 선화 추출(Manga Lineart)이 필요했습니다.
- **채도 높은 색 밝히기**: Helmholtz–Kohlrausch 효과에 따라 채도 높은 색을 밝게 해서, 빨간 옷이 검은 덩어리가 되지 않게 합니다.
- **어두운 부분 나누기**(기본은 켜짐): 큰 먹칠 영역에서 밝은 쪽을 진한 톤으로 바꿉니다. 검은 치마 같은 짙은 회색 천에 잘 맞고, 짙은 옷에 입체감이 생깁니다. 검은 머리카락이 잘게 쪼개지는 이미지에서는 꺼 주세요.
- **옅은 윤곽선**(기본은 꺼짐): Canny 엣지 중에서 길고 가는 직선만 남겨, 안개 속 건물에 윤곽을 더합니다.
- **이미지에 맞춘 기본값**: 불러올 때 밝기 분포로 레벨을 정해(순백 배경은 제외) 어두운 장면이 새까만 페이지가 되지 않게 합니다. 선명한 색이 많은 이미지에서는 채도 높은 색 밝히기를 자동으로 켭니다.
- **10가지 망**: 원형 점, 사각 점, 마름모 점, 체인 점, 평행선, 교차선, 물결선, 모래결, 동심원, 집중선.
- **출력 해상도 분리**: 망 간격이 10 px보다 작으면 더 높은 해상도로 출력해서 원형 점이 제대로 둥글게 나오게 합니다.

모든 크기는 너비 1024 px 기준으로 정규화되어 있어서, 같은 설정이면 어떤 해상도에서도 같은 모습이 나옵니다.

## 개발

페이지는 [`src/app.html`](src/app.html)(도구 본체)과 [`src/seo.mjs`](src/seo.mjs)(언어별 제목과 설명)로 만듭니다. 수정한 뒤 다음을 실행합니다.

```sh
node scripts/build.mjs
```

영어 입구 페이지 `index.html`, 각자 meta를 가진 `zh/`, `ja/`, `ko/` 입구 페이지, `sitemap.xml`, `robots.txt`, `manifest.webmanifest`, 그리고 LLM과 에이전트용 `llms.txt`, `llms-full.txt`, `index.md`를 만듭니다. Node.js만 있으면 되고 다른 의존성은 없습니다.

## Qwen 방식과의 비교

ComfyUI-MangaScreen에는 Qwen-Image로 이미지를 만화풍으로 다시 그린 뒤 Manga Finish에 넣는 방식도 있습니다. 그 저장소의 예시와 같은 입력으로 비교하면 다음과 같습니다.

- **선화가 깔끔한 플랫 채색 인물**: 거의 비슷합니다. 가는 선 덕분에 눈, 손가락, 옷 주름의 선은 Qwen 버전보다 더 많이 나옵니다. 명암 차이는 주로 레벨 설정에서 오며, "화이트 포인트"를 낮추면 가까워집니다.
- **배경과 복잡한 장면**: 의미를 판단해야 하는 곳에서 뒤처집니다. 검은 치마를 진한 톤과 먹칠로 나누는 표현은 어두운 부분 나누기로 비슷하게 만들 수 있지만, 하한값은 이미지마다 조정해야 합니다. Qwen은 안개 속 고층 건물에 윤곽과 창을 그려 넣지만, 옅은 윤곽선으로 되살릴 수 있는 것은 직선 몇 개뿐입니다. 나무는 전체적으로 어둡고 무겁게 나옵니다.

이미지 처리로는 "이것이 무엇이고 어떻게 그려야 하는지"를 임곗값으로 흉내 낼 수밖에 없으므로, 배경이 많은 이미지는 이미지마다 조정이 필요합니다.
