# manga-filter

カラーイラストを、スクリーントーンを貼ったモノクロ漫画に変換します。一般的な画像処理だけを使い、機械学習モデルは使いません。

**オンラインで使う：<https://jannchie.github.io/manga-filter/>**

ツール全体は [`index.html`](index.html) の 1 ファイルです。ブラウザで開いて画像をドロップするか貼り付け、スライダーを動かすと結果がすぐに更新されます。処理はすべてブラウザの Web Worker 内で行うので、インストールは不要で、画像が手元から外に出ることもありません。

## 使い方

1. <https://jannchie.github.io/manga-filter/> を開くか、最近のブラウザで `index.html` を開きます。
2. 「画像を開く」を押すか、画像をキャンバスにドラッグします。クリップボードからの貼り付けもできます。
3. スライダーを調整します。「押して原画を表示」を押している間は元画像と見比べられます。
4. 「パラメータをコピー」で現在の設定を JSON としてコピーし、「基準に戻す」で初期値に戻します。

プレビューでは、ホイールでポインタ位置を中心に拡大縮小、ドラッグで移動、ダブルクリックでウィンドウに合わせる表示と 1:1 を切り替えます。`0` でウィンドウに合わせ、`1` で 1:1 です。スライダーはクリックで選択した後にホイールで微調整でき（Shift で 10 段階ずつ）、ダブルクリックで初期値に戻ります。

## 処理の内容

処理の流れは [ashukae/ComfyUI-MangaScreen](https://github.com/ashukae/ComfyUI-MangaScreen) の Manga Levels と Manga Finish ノードの移植です（MIT、ライセンスは [`licenses/`](licenses/)）。グレースケールのレベル補正、線とベタのインク層、網点除去と平坦化、小さな領域をまとめた階調の割り当て、グラデーショントーン、ページ全体でそろえた網、ベタの中に白線を抜く処理を行います。そのうえで次を加えています。

- **細い線**：元画像の L\* チャンネルに 2 つのスケールの DoG（ガウシアン差分）をかけ、口や鼻、薄い輪郭線を拾い直します。元の実装では外部のニューラル線画抽出（Manga Lineart）が必要でした。
- **彩度の高い色を明るく**：Helmholtz–Kohlrausch 効果に沿って彩度の高い色を明るくし、赤い服が黒い塊にならないようにします。
- **暗部の分割**（初期値はオフ）：大きなベタのうち明るい部分を濃いトーンに変えます。黒いスカートのような濃いグレーの布に向いています。黒髪を細切れにすることもあるので、画像ごとに有効にしてください。
- **淡い輪郭線**（初期値はオフ）：Canny のエッジから長く細い直線だけを残し、霞んだ建物に輪郭を足します。
- **10 種類の網**：丸点、角点、菱形点、チェーン点、平行線、クロス線、波線、砂目、同心円、集中線。
- **出力解像度を分離**：網の間隔が 10 px に満たない場合は高い解像度で出力し、丸点がきちんと丸くなるようにします。

サイズはすべて幅 1024 px を基準に正規化しているので、同じ設定ならどの解像度でも同じ見た目になります。

## 開発

ページは [`src/app.html`](src/app.html)（ツール本体）と [`src/seo.mjs`](src/seo.mjs)（言語ごとのタイトルと説明）から生成します。編集したら次を実行します。

```sh
node scripts/build.mjs
```

英語の入口ページ `index.html`、それぞれの meta を持つ `zh/`・`ja/`・`ko/` の入口ページ、`sitemap.xml`、`robots.txt`、`manifest.webmanifest`、LLM やエージェント向けの `llms.txt`・`llms-full.txt`・`index.md` を書き出します。必要なのは Node.js だけで、依存パッケージはありません。

## Qwen を使う流れとの比較

ComfyUI-MangaScreen には、Qwen-Image で画像を漫画風に描き直してから Manga Finish にかける流れもあります。同リポジトリの作例と同じ入力で比べると、次のようになります。

- **線画のはっきりしたフラット塗りの人物**：ほぼ同等です。細い線のおかげで、目や指、服のしわの線は Qwen 版より多く出ます。明暗の違いは主にレベル補正の設定によるもので、「白点」を下げると近づきます。
- **背景や込み入った場面**：意味の判断が必要なところで差が出ます。黒いスカートを濃いトーンとベタに分ける表現は暗部の分割で近づけられますが、下限は画像ごとに調整が必要です。Qwen は霞んだ高層ビルに輪郭と窓を描きますが、淡い輪郭線で取り戻せるのは数本の直線だけです。木々は全体に暗く重くなります。

画像処理では「これは何で、どう描くべきか」をしきい値で近似するしかないため、背景の多い画像は画像ごとの調整が必要です。
