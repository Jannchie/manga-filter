# manga-filter

把彩色插画转成带网点的黑白漫画，只用常规的图像处理，不用任何机器学习模型。

**在线使用：<https://jannchie.github.io/manga-filter/>**

整个工具就是 [`index.html`](index.html) 这一个文件：用浏览器打开，拖入或粘贴图片，拖动滑块实时调整效果。所有计算都在浏览器的 Web Worker 里完成，不需要安装任何东西，图片也不会离开你的电脑。

## 用法

1. 打开 <https://jannchie.github.io/manga-filter/>，或者用较新的浏览器打开 `index.html`。
2. 点「打开图片」，或者把图片拖到画布上，也可以直接粘贴剪贴板里的图片。按钮旁边的两张缩略图是示例图。
3. 先挑一个预设再调滑块。「自动」按图片定黑白场、饱和色提亮和线数，其他预设在它的基础上改。按住「按住看原图」可以和原图对照。
4. 「复制参数」把当前设置复制成 JSON；「恢复默认」回到这张图的自动设置。

预览区里，滚轮以指针为中心缩放，拖动平移，双击在适应窗口和 1:1 之间切换；`0` 是适应窗口，`1` 是 1:1。点选滑块后可以用滚轮微调（按住 Shift 一次十档），双击滑块复位。

## 做了什么

管线移植自 [ashukae/ComfyUI-MangaScreen](https://github.com/ashukae/ComfyUI-MangaScreen) 的 Manga Levels 和 Manga Finish 节点（MIT，许可证见 [`licenses/`](licenses/)）：灰度色阶、墨线与实黑的墨层、去网与压平、分档并合并碎块、渐变网点、整页对齐的网屏、在实黑里切出白线。在此基础上加了：

- **细线稿**：在原图的 L\* 通道上做双尺度高斯差分（DoG），补回嘴、鼻和浅色轮廓。原版要外接神经网络线稿（Manga Lineart）才有这些线。
- **饱和色提亮**：按 Helmholtz–Kohlrausch 效应调亮高饱和色，红衣服不再压成一块黑。
- **暗部分层**（默认开启）：把大块实黑里偏亮的部分改成深网点，适合黑裙子这类深灰布料，深色衣服也更有体积感。如果把某张图的深色头发切碎了，就关掉它。
- **淡边描线**（默认关闭）：Canny 边缘里只保留又长又细的直线段，给雾中的建筑补轮廓。
- **自适应默认值**：载入图片时按亮度分布定色阶（纯白底不计入），暗场景不再变成一整片黑；鲜艳的颜色多时自动开启饱和色提亮。
- **10 种网点**：圆点、方点、菱形点、链点、平行线、交叉线、波纹线、砂目、同心圆、集中线。
- **出图分辨率独立**：网点间距不足 10 像素时放大出图，圆点才画得圆。

所有尺寸都按 1024 像素宽归一，同一组参数在任何分辨率下效果相同。

## 开发

页面由 [`src/app.html`](src/app.html)（工具本身）和 [`src/seo.mjs`](src/seo.mjs)（各语言的标题与描述）构建。修改后运行：

```sh
node scripts/build.mjs
```

它会生成英文入口页 `index.html`、各自带 meta 的 `zh/`、`ja/`、`ko/` 入口页、`sitemap.xml`、`robots.txt`、`manifest.webmanifest`，以及给 LLM 和 agent 读的 `llms.txt`、`llms-full.txt`、`index.md`。只需要 Node.js，没有其他依赖。

## 和 Qwen 流程的对比

ComfyUI-MangaScreen 还有一条流程：先用 Qwen-Image 把图重画成漫画，再接 Manga Finish。用该仓库示例里的同一组输入对比：

- **线稿清晰的平涂人物**：基本持平。细线稿让眼睛、手指、衣褶的线条比 Qwen 版还多。明暗上的差别主要来自色阶设置，把「白场」调低就能接近。
- **背景和复杂场景**：在需要语义判断的地方落后。黑裙子分成深网点和实黑，可以用暗部分层逼近，但它的下限要按图调；Qwen 能给雾中高楼画出轮廓和窗格，淡边描线只补得出几条直边；树丛整体偏黑偏重。

图像处理只能用阈值去逼近「这是什么、该怎么画」，所以背景多的图需要按图调参。
